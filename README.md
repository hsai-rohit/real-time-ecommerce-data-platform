# Real-Time E-Commerce Data Platform

This will be an end-to-end, production-style e-commerce DataOps project.

- E-commerce data is synthetic.
- Initial real-time behavior is simulated and batch-based.
- We will only claim real-time functionality when it is actually implemented.

## Status

Project initialization.

## Data Sources

The project currently includes fictional, deterministic local source data: customer and product CSV files, an SQLite operational source for orders and payments, and a small local mock REST API for website events. Real-time behavior remains simulated and batch-oriented; no ingestion or cloud components are implemented.
